# Metalúrgica do Maurição

Site institucional da Metalúrgica do Maurição — portões, grades, estruturas metálicas e serralheria.

## Publicar no GitHub Pages

1. Vá em **Settings → Pages**
2. Em **Source**, escolha **Deploy from a branch**
3. Branch: **main** / pasta: **/ (root)**
4. Salve

O site ficará em:
https://flaviomirandadasilva06-gif.github.io/metalurgica-mauricao/

## Arquivos necessários

Todos os arquivos da pasta `metalurgica-mauricao` devem estar na **raiz** do repositório (mesmo nível do `index.html`).
